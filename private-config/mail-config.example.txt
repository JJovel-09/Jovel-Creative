PRODUCTION SECRET LOCATION

Create the real SMTP credential outside public_html and outside Git at:

~/.config/jovelcreative/mail-config.php

The tracked file private-config/mail-config.php is only a secret-free loader. Do not put the mailbox password in that tracked file.

Use this structure for ~/.config/jovelcreative/mail-config.php:

<?php
return [
    'host'       => 'smtp.hostinger.com',
    'port'       => 465,
    'encryption' => 'smtps',
    'username'   => 'hello@jovelcreative.com',
    'password'   => 'ENTER THE MAILBOX PASSWORD ON THE SERVER ONLY',
    'from'       => 'hello@jovelcreative.com',
    'to'         => 'hello@jovelcreative.com',
];

Recommended permissions:
- ~/.config/jovelcreative directory: 700
- mail-config.php: 600

For Hostinger port 587, change port to 587 and encryption to starttls.
Never commit the real secret file or paste its contents into chat.
